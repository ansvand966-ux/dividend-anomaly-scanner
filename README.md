# Dividend Anomaly Scanner (Moscow Exchange)

Python-скрипт для поиска аномалий дивидендной доходности на российском рынке. Инструмент ищет ситуации, когда цена акции не восстановилась после выплаты дивидендов, оставляя инвесторам "подарочную" доходность (Forward Yield).

## 📊 Логика работы
Скрипт сравнивает **текущую рыночную цену** (через `moexalgo`) с **суммой фактически выплаченных дивидендов** за последний год.
Если отношение `Дивиденд / Цена` превышает заданный порог, акция попадает в список аномалий.

## 🛠 Технологии
*   **Python 3.x**
*   **moexalgo** — для получения официальных данных с Московской биржи.
*   **SQLite** — для сохранения найденных сигналов в локальную базу.

## 🚀 Установка и запуск

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ansvand966-ux/dividend-anomaly-scanner.git
    ```
2.  Установите зависимости:
    ```bash
    pip install moexalgo pandas
    ```
3.  Запустите сканер:
    ```bash
    python scanner.py
    ```
